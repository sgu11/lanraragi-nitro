# LANraragi Nitro

LANraragi Nitro is a feature fork of
[LANraragi](https://github.com/Difegue/LANraragi), focused on reader usability,
library workflows, duplicate review, and deployment reliability.

[한국어](README.ko.md) · [Upstream project](https://github.com/Difegue/LANraragi)

## Highlights

- Enhanced paginated and double-page reading, adaptive spread alignment,
  session-aware navigation, fullscreen controls, and optional blank-border
  cropping.
- Faster library rendering, selection and bulk-action workflows, responsive
  archive cards, and in-place deletion refreshes.
- Cover-focused duplicate review with versioned fingerprints, focused
  comparison queues, and safer archive handling.
- Redis, archive-ingestion, thumbnail, reader-cache, and request-path
  reliability improvements for larger libraries.
- Additional Catppuccin themes, including an OLED variant.

## Compatibility

This repository periodically incorporates changes from LANraragi's `dev`
branch. Installation, configuration, and plugin development generally follow
the upstream project; refer to the
[official LANraragi documentation](https://sugoi.gitbook.io/lanraragi/) for the
base application.

This is an independent fork. Please reproduce issues against upstream
LANraragi before reporting them to the upstream project.
